### 演练记录（按 DoD 条目）

  `mode=auto`、`url=https://accounts.google.com/o/oauth2/v2/auth?client_id=…&code_challenge=…&code_challenge_method=S256`

- `GET /admin/pool/auth/qr` → 200，`content-type: image/png`、`cache-control: no-store`，
  主体 10420 字节、PNG 魔数 `89 50 4e 47 0d 0a 1a 0a` ✓。
- **红线核对**：演练未提交 code/未走 token 端点——以 `POST /admin/pool/auth/cancel` 收尾 →
  `{"ok":true,"phase":"idle"}`。真实 Google 登录（DoD ① 完整闭环）需用户在有浏览器环境执行。
- 会话守卫：无 cookie `GET /admin/me` → 401；带 cookie → 200。CSRF：无
  `x-requested-with` 的变更方法（含 `/admin/login`）→ 403。错误密码（带 CSRF 头）→
  401 且耗时 322ms（300ms damping 生效）。

### ③ 429 演练（硬限流 → 冷却 + 自动切换；全冷却 → 429 + 倒计时）

- **a) 切换（boot #1，`FAKE_AGY_FAIL_HOME=alpha.dir`）**：请求 1 → **502**，
  `{"error":{"message":"Google Antigravity quota / rate limit reached: 429 RESOURCE_EXHAUSTED: Individual quota reached for this model. Resets in 21m25s.","type":"api_error","code":"AGY_ERROR"}}`
  （上游真实文本逐字透传）；请求 2（不同 prompt）→ **200**。服务端结算行证明换号：

```json
{"ok":false,"code":"AGY_ERROR","accountId":"acc_1788187843127_r38jr"}   ← alpha 硬失败
{"ok":true,"code":"OK","accountId":"acc_1788187843128_p1x58"}           ← 下一个请求自动切到 beta
```

  `/admin/pool` 同步可见：alpha `cooldowns.google.reason` 含 `Resets in 21m25s`，
  `activeAccountIds.google = beta`。冷却跨重启持久（pool.json）。
- **b) 全池冷却（boot #2，`FAKE_AGY_MODE=rate-limit`）**：请求 1 → **502** AGY_ERROR
  （beta 硬失败进冷却）；请求 2 → **429**：

```json
retry-after: 1183
{"error":{"message":"All Antigravity accounts in pool are in cooldown for google (earliest reset in 1183s). Add an account or wait for reset.","type":"rate_limit_error","code":"POOL_EXHAUSTED"}}
```

  `retry-after: 1183` ≈ alpha 21m25s 冷却的剩余时间——倒计时取池内最早重置时刻 ✓。

## 演练中发现（非阻塞，整改候选）

1. **`Content-Type: application/x-www-form-urlencoded` → 500**：`curl -d` 默认该头时
   TypeBox content-type parser 抛 `Unsupported Media Type`，被 error handler 归为
   500 "internal error"（应为 415）。演练中首次 clear-cooldown 即踩中。建议 M4/M5
   加固：content-type parser 错误映射为 415（`setErrorHandler` 细分 FST_ERR_CTP 异常）。
2. m2 已踩过的 shim 坑再次确认：`resolveAgyBin` 对 PATH 上的 `.exe` 优先于 `.cmd` shim
   —— 网关部署机若想强制指定 agy 路径，应保证 `AGY_PROXY_BIN` 指向 `.exe` 或保证 PATH
   上无真 agy。
