### 演练中发现的缺陷（已修复）

- **`src/index.ts` 模型发现回传了错误数据**：catalog refresh 回调复用 `probeProcess`，
  其 ProbeResult 只暴露解析后的 version 字符串，导致目录永远是 fallback（列表里是内置
  fallback 模型而非 `agy models` 的真实输出）。改为直接 `startAgyProcess(['models'])`
  读取原始 stdout。该缺陷在 M1 未暴露（无 models 路由消费发现结果）；OA8a 演练时发现，
  单独提交修复。fake-agy `models` JSON 输出经 `parseModelsOutput` → 目录
  `[gemini-3-6-flash, claude-sonnet-4-6]`（`gemini-3-6-flash-high` 因 fake-agy 该模式
  未输出 effort 后缀而按独立 id 处理——实际两次启动输出均为两模型形状，转录如上）。
